## Menambah & Menghapus

* `push()` — menambahkan elemen ke akhir array
* `pop()` — menghapus elemen terakhir
* `unshift()` — menambahkan elemen ke awal array
* `shift()` — menghapus elemen pertama
* `splice()` — menambah, menghapus, atau mengganti elemen pada posisi tertentu

## Mencari

* `find()` — mencari elemen pertama yang memenuhi kondisi
* `findIndex()` — mencari index pertama yang memenuhi kondisi
* `findLast()` — mencari elemen terakhir yang memenuhi kondisi
* `findLastIndex()` — mencari index terakhir yang memenuhi kondisi
* `includes()` — mengecek apakah elemen ada di array
* `indexOf()` — mencari index pertama dari elemen tertentu
* `lastIndexOf()` — mencari index terakhir dari elemen tertentu

## Iterasi

* `forEach()` — menjalankan fungsi untuk setiap elemen
* `map()` — membuat array baru dari setiap elemen
* `filter()` — membuat array baru berisi elemen yang memenuhi kondisi
* `reduce()` — menggabungkan semua elemen menjadi satu nilai
* `reduceRight()` — melakukan `reduce()` dari elemen terakhir
* `some()` — mengecek apakah ada elemen yang memenuhi kondisi
* `every()` — mengecek apakah semua elemen memenuhi kondisi
* `flatMap()` — melakukan `map()` lalu meratakan hasilnya satu level

## Mengurutkan & Membalik

* `sort()` — mengurutkan elemen array
* `reverse()` — membalik urutan elemen
* `toSorted()` — membuat array baru dengan elemen yang sudah diurutkan
* `toReversed()` — membuat array baru dengan urutan elemen dibalik

## Menggabungkan & Memotong

* `concat()` — menggabungkan array dengan array atau nilai lain
* `slice()` — mengambil sebagian elemen tanpa mengubah array asli
* `join()` — menggabungkan elemen menjadi string
* `flat()` — meratakan array bersarang

## Mengubah / Menghasilkan String

* `toString()` — mengubah array menjadi string
* `toLocaleString()` — mengubah array menjadi string menggunakan format lokal

## Lainnya

* `at()` — mengambil elemen berdasarkan index
* `fill()` — mengisi elemen dengan nilai tertentu
* `copyWithin()` — menyalin elemen ke posisi lain dalam array
* `entries()` — menghasilkan iterator berisi pasangan index dan nilai
* `keys()` — menghasilkan iterator berisi index
* `values()` — menghasilkan iterator berisi nilai

## Static Array Methods

* `Array.isArray()` — mengecek apakah nilai merupakan array
* `Array.from()` — membuat array dari iterable atau array-like
* `Array.of()` — membuat array dari argumen yang diberikan
